#  Сапер на языке Jack

Проект представляет собой классическую игру «Сапер», разработанную на языке **Jack**.

Игра компилируется в байт-код для виртуальной машины (VM), который затем исполняется в эмуляторе среды Nand2Tetris

---

##  Игровой процесс и Особенности

*   **Поле 10x10 ячеек** с автоматической и случайной генерацией 10 мин
*   **Рекурсивное открытие пустых зон:** При клике на клетку с 0 мин вокруг, игра автоматически раскрывает все соседние безопасные ячейки
*   **Контроль состояний:** Игра отслеживает победу и поражение, блокируя управление по завершении матча

---

##  Управление

Для управления используется клавиатура:
*   **Стрелки (Вверх, Вниз, Влево, Вправо)** - Перемещение курсора по полю
*   **Пробел (Space)** - Открыть выбранную ячейку
*   **Клавиша [F]** - Установить / снять флаг
*   **Клавиша [Q]** - Выход из игры

---

##  Архитектура проекта

1.  **`Main.jack`** - Точка входа. Инициализирует и запускает игровой контроллер
2.  **`MinesweeperGame.jack`** - Главный игровой менеджер. Обрабатывает ввод с клавиатуры, отвечает за движение и отрисовку курсора, а также управляет состояниями игры (`Play`, `Win`, `Lose`)
3.  **`Board.jack`** - Логика игрового поля. Хранит двумерный массив ячеек, отвечает за генерацию мин, подсчет цифр вокруг них, рекурсивный алгоритм раскрытия зон и попиксельный вывод графики
4.  **`Square.jack`** - Модель отдельной ячейки. Хранит её состояние в памяти (наличие мины, флажка, статус открытия, количество мин-соседей)
5.  **`Random.jack`** - Модуль генерации псевдослучайных чисел на основе линейного конгруэнтного метода (LCG) для случайного распределения мин на поле

---


### 1. [Каскадное открытие пустых ячеек (Рекурсия)](./src/Board.jack#L157)
* Реализация классического алгоритма заливки (Flood Fill). Если открытая ячейка имеет `0` мин вокруг, функция рекурсивно вызывает сама себя для всех 8 соседей

### 2. [Паттерн «Умная ячейка» и устранение графических артефактов](./src/Board.jack#L92)
* Чтобы курсор при движении по черным кнопкам не оставлял за собой белые "дыры", вся логика отрисовки инкапсулирована в один метод. Он оценивает состояние ячейки в памяти (`Revealed`, `Flagged`, `HasMine`) и перерисовывает её с нуля, стирая любые наложения курсора без остатка

### 3. [Неблокирующий сбор энтропии для Random Seed](./src/MinesweeperGame.jack#L22)
* Чтобы мины каждый раз генерировались в новых местах, игра использует бесконечный цикл на стартовом экране ("Press ANY KEY..."). Пока игрок не нажмет клавишу, увеличивается счетчик `seedCounter`

### 4. [Реализация LCG-генератора случайных чисел](./src/Random.jack)
* Поскольку на платформе Hack нет встроенного аппаратного датчика случайных чисел, генерация мин реализована через линейный конгруэнтный метод (LCG). Каждое следующее число вычисляется по формуле: 
    $$seed = (seed \cdot 25173 + 13849) \pmod{32767}$$
    Константы подобраны так, чтобы период повторения псевдослучайной последовательности был максимальным для 16-битного знакового целого числа, что гарантирует честное и непредсказуемое распределение мин при каждом новом запуске
